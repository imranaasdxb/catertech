Backend & Admin Panel — Production-Ready Plan

Architecture Decision: Single Next.js Project

No separate backend folder is needed. Next.js App Router handles everything:





Route Handlers (app/api/...) = REST API endpoints



Server Actions = form submissions



/admin route group = the admin panel UI

This means one codebase, one deployment, zero CORS friction.



Tech Stack





Database: Neon (PostgreSQL serverless) via @neondatabase/serverless



ORM: Drizzle ORM — lightweight, SQL-first, perfect for serverless



Auth: Auth.js v5 (NextAuth) with Drizzle adapter — credentials provider for email/password



Images: Cloudflare R2 via @aws-sdk/client-s3 (S3-compatible presigned URLs)



Validation: Zod schemas for all forms and API inputs



Passwords: bcryptjs for hashing

                   isAvailable, isFeatured, authorId, published, createdAt, updatedAt

                   serviceInterest, message, attachmentUrl, status, createdAt
rfqSubmissions   → id, companyName, email, phone, lineItems (jsonb),
                   attachmentUrls[], status, createdAt
contactMessages  → id, fullName, email, phone, message, status, createdAt



How Roles Work

flowchart TD
    Login[Admin Login] --> AuthCheck{role?}
    AuthCheck -->|super_admin| FullAccess["All pages + Users page"]
    AuthCheck -->|admin| LimitedAccess["Products, Blogs,\nQuotations, Enquiries, RFQ, Contacts"]
    LimitedAccess --> UsersBlocked["403 on /admin/users"]





middleware.ts blocks all /admin/* routes (except /admin/login) unless authenticated



/admin/users additionally checks role === 'super_admin' server-side

Image Upload Flow (Cloudflare R2)

sequenceDiagram
    participant Browser
    participant NextAPI as "Next.js API /api/upload"
    participant R2 as "Cloudflare R2"
    participant DB as "Neon DB"

    Browser->>NextAPI: POST {filename, contentType}
    NextAPI->>R2: Generate presigned PUT URL
    R2-->>NextAPI: presignedUrl
    NextAPI-->>Browser: {presignedUrl, publicUrl}
    Browser->>R2: PUT file directly (no server proxy)
    R2-->>Browser: 200 OK
    Browser->>DB: Save publicUrl in product/blog record

This keeps file data off your Next.js server entirely.
